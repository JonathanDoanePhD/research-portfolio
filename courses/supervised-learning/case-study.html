The design problem

The source PowerPoint was built for facilitated instruction. Live-session directions, progressive reveals, repeated explanations, large datasets, and code needed transformation for independent learning. The intended performance was to frame a supervised learning task, choose meaningful inputs and a target, recommend a model under stated requirements, and interpret results cautiously.

The learning journey

  1. Foundations of Supervised Learning: AI/ML relationships, labeled examples, regression versus classification, and a target-encoding check.
  2. Multiple Linear Regression: multiple predictors, a small source-dataset excerpt, a modeling process, readable Python, and coefficient interpretation.
  3. Logistic Regression: probabilities, sigmoid reasoning, thresholds, scaling, target leakage, and subgroup questions.
  4. Decision Trees & Random Forests: worked split reasoning, tree rules, ensemble predictions, and held-out evaluation.
  5. Choosing the Right Model: four application scenarios with explicit requirements and explanatory rationales.
  6. Final Knowledge Check: eight application-oriented questions, explanatory feedback, an 80% passing score, and unlimited retries.

Technical and presentation decisions

Source content was retained while newly authored guidance was recorded separately. Official scikit-learn documentation supported train-only preprocessing, leakage prevention, held-out evaluation, and model behavior. The illustrative sigmoid chart was generated mathematically in Python, with alternative text and an explanatory caption. Native code preserves indentation and offers Copy; narrow-screen instructions explain horizontal scrolling for code and tables. Existing Rise branding was retained.

QA findings and corrections

  • Scenario cards initially needed internal scrolling. Text was shortened and large cards selected for clearer desktop and vertical mobile layouts.
  • Answer shuffling produced a mismatch between a visible selection and an accessibility announcement. Shuffling was disabled, correct positions remained varied, and keyboard selection was retested.
  • Quiz testing verified 75% Failed, retry reset, and 100% Passed, alongside answer and feedback accuracy.
  • Tabs, process screens, card flips, knowledge checks, navigation, image zoom, and selected keyboard controls were tested in Rise Preview.
  • AI Tutor was disabled with Jonathan's explicit approval, excluding unreviewed dynamic AI answers from the final experience.
  • The final Web export passed ZIP integrity checks, retained the verified Python resource, and excluded the rejected import.

Evidence and limits

QA used Rise desktop, tablet, and phone previews and export inspection. This is a portfolio demonstration, not an LMS deployment. No learner-impact study, independent human SME review, full assistive-technology audit, or WCAG certification has been completed. No Storyline artifact was created because a supported desktop authoring surface was unavailable. Completion or proficiency gains are not claimed.
